<h1>how do we see the world</h1>
<h2>Typography & Interaction Project 4</h2>
<p>This is a multimedia collaborative project. Designers are asked to design and add to their asigned are.na channel based on their own interpretation.</p> 

<h3>About Channel</h3>
<p>This channel is originally made by Kimaya.</p> 
<em>
  As someone who has always been drawn to maps, I used that as a starting point for this collection. I wanted to explore the ways in which we see the world around us, the representations we have created over time and how we interact with our surroundings. This is multi-media collection explores how maps are always subjective, they are representations created by us, revealing internal perspectives.
</em> 

<h3>Design</h3>
<p>The collection starts from looking at maps and navigations in physical space, and extends to how we feel and interpret everything around us. I designed a field view with blocks in random order so everyone can have their own unique navigation experience on the site, because I think how people navigate and understand their surroundings is intuitive and personal. There is also a randomize button to change up the order of the blocks.</p> 

<h3>Technical Leanings</h3>

<li>I also got to build on my css animation skills a bit more. </li> 
<li>I learned how to work with are.na API.</li> 
<li>In terms of building on existing knowledge, I got to use some properties in CSS that I had not gotten to use but meant to try out such as mask-image and gradients. I honed in my knowledge in grid and flex by using a lot of them. I also got more farmiliar with nesting.</li>
